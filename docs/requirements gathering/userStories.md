| User Story Number | User Story Description |
|-------------------|------------------------|
| 1                 | As a student user, I want to see my spending per month trend so that I can understand my spending habits over time and identify any patterns. |
| 2                 | As a student user, I want to see the total amount I spent throughout the year so that I have a clear picture of my overall expenses. |
| 3                 | As a student user, I want to see the total number of items I bought so that I can gauge the volume of my purchases. |
| 4                 | As a student user, I want to see the brand I engaged with the most so that I can understand which brands I prefer and spend on frequently. |
| 5                 | As a student user, I want to see the total number of purchases I made so that I can track how often I shopped. |
| 6                 | As a student user, I want to see how much I saved through discounts so that I know the value of my savings using Unidays. |
| 7                 | As a student user, I want to see my most frequently visited category so that I know which types of products or brands I am most interested in. |
| 8                 | As a student user, I want to be able to share my recap on social media so that I can showcase my shopping journey to my friends. |
| 9                 | As a student user, I want to view my friends' recaps so that I can see what they purchased and potentially discover new brands. |
| 10                | As a student user, I want to compare my recap with my friends' recaps so that I can see how my spending and savings compare to theirs. |
